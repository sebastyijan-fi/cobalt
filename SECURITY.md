# Security Policy

## Supported Versions

Only the latest release of Cobalt is supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. Do **not** open a public GitHub issue.

- **Email**: [security@cobalt.example.com] (Placeholder)
- **Encryption**: Please use PGP if possible (Key ID: TBD).

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Disclosure Policy

- We follow a 90-day disclosure policy from the time the vulnerability is reported.
- We will provide a CVE ID where appropriate.
- We will credit you in the release notes and `SECURITY.md` acknowledgments.

## Fuzzing and Hardening

Cobalt is continuously fuzzed using `libFuzzer`. We take binary format safety seriously.
